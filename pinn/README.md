# PINN — 物理信息神经网络

用神经网络求解偏微分方程。和前面 MLP/CNN 最大的区别：**不需要数据集**，
数据是在物理区域内随机采样的"配点"，损失由"物理方程残差"和"边界条件"两部分构成。

## 快速开始

```bash
pip install -r requirements.txt   # 在项目根目录执行一次（依赖与其它项目相同，无需额外安装）
python train.py                   # 训练（结果保存在 weights/）
python visualize.py               # 与精确解对比画图
```

## 默认任务：一维泊松方程

求解 -u''(x) = π²·sin(πx)，x ∈ [0, 1]，边界条件 u(0) = u(1) = 0，精确解为 u(x) = sin(πx)。

训练损失 = λ_pde × PDE残差平方和 + λ_bc × 边界条件平方和。3000 步后相对 L2 误差预期 **< 1e-3**。

## 项目结构说明

与 mlp / cnn 的骨架保持一致（`config.py` / `model.py` / `train.py`），两个文件因任务特性做了替换：

| 文件 | mlp/cnn | pinn |
|---|---|---|
| 数据来源 | `dataset.py`（下载数据集） | `pde.py`（方程 + 配点采样，数据"无限"） |
| 结果展示 | `predict.py`（预测图片） | `visualize.py`（对比精确解） |

## 推荐练习顺序

1. 跑通默认配置，看懂"残差损失 + 边界损失"这个核心思想
2. 在 `pde.py` 里换一个方程，比如改成 u''(x) = 2、u(0) = u(1) = 0（精确解为抛物线 u = x(x-1)）
3. 把 `activation` 换成 `relu`，观察训练是否退化，体会为什么 PINN 要用光滑激活函数
4. 改 `lambda_pde` / `lambda_bc` 的权重比，体会两个损失如何博弈
5. 挑战：换成 1D 热方程 u_t = u_xx（加时间维度，输入变 (x, t)），或 Burgers 方程
