# MLP — 全连接神经网络图像分类

用最基础的多层感知机（MLP）做图像分类，适合作为深度学习的第一个练习项目。
数据集由 torchvision 自动下载，无需手工准备。

## 快速开始

```bash
pip install -r requirements.txt   # 在项目根目录执行一次
python train.py                   # 训练（结果保存在 weights/）
python predict.py                 # 用最后保存的权重预测并可视化
```

## 默认任务：Fashion-MNIST 10 分类

- 图像：28x28 灰度图，共 10 类衣物（T恤、裤子、套头衫、连衣裙、外套、凉鞋、衬衫、运动鞋、包、靴子）
- 训练集 60000 张，测试集 10000 张，代码自动从训练集切出 10% 作为验证集
- 默认结构（784 -> 512 -> 256 -> 128 -> 10）+ 15 个 epoch，预期验证集准确率 **约 88%~90%**

## 推荐数据集与任务

| 数据集 / 任务 | 说明 | 难度 |
|---|---|---|
| MNIST | 手写数字 0-9 分类，最简单，适合先跑通流程 | ⭐ |
| Fashion-MNIST | 10 类衣物分类，**推荐入门**，比 MNIST 更有区分度 | ⭐⭐ |
| 自定义回归任务 | 如 `y = x² + noise` 曲线拟合，练习回归（把输出改成 1 个标量 + MSE 损失） | ⭐⭐ |

## 建议练习顺序

1. 先跑通默认配置，把训练循环里每行代码的含义看懂（前向、损失、反向、更新）
2. 改 `hidden_dims`、`dropout`、`lr`，观察验证集准确率怎么变，体会"过拟合/欠拟合"
3. 对比 MNIST 和 Fashion-MNIST 的效果差异，思考为什么
4. 把任务改成回归，体会分类（CrossEntropy）与回归（MSE）在损失函数上的区别
