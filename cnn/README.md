# CNN — 卷积神经网络图像分类

用经典的小型 CNN（Conv + BN + ReLU + MaxPool）做图像分类，展示卷积、池化、批归一化等核心概念。

## 快速开始

```bash
pip install -r requirements.txt   # 在项目根目录执行一次
python train.py                   # 训练（结果保存在 weights/）
python predict.py                 # 用最后保存的权重预测并可视化
```

## 默认任务：CIFAR-10 分类

- 图像：32x32 彩色图（3 通道），共 10 类（飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船、卡车）
- 训练集 50000 张，测试集 10000 张；训练时使用随机裁剪 + 随机翻转做数据增强
- 默认结构：3 层 Conv 块（32/64/128 通道）+ 学习率衰减，30 个 epoch，预期测试集准确率 **约 80%~85%**

## 推荐数据集与任务

| 数据集 | 说明 | 难度 |
|---|---|---|
| CIFAR-10 | 10 类物体分类，**推荐入门** | ⭐⭐ |
| CIFAR-100 | 100 类细粒度分类，把 `config.py` 里 `dataset` 改成 `cifar100`、`num_classes` 改成 `100` | ⭐⭐⭐ |
| SVHN | 真实街景门牌号数字识别，自带噪声与遮挡，torchvision 可直接下载 | ⭐⭐⭐ |

## 建议练习顺序

1. 跑通默认配置，对照网络结构理解每层输出尺寸的变化（32 → 16 → 8 → 4）
2. 去掉数据增强（`RandomCrop` / `RandomHorizontalFlip`），观察准确率下降，体会增强的作用
3. 改通道数、层数，看参数量与效果如何取舍
4. 挑战：把网络改造成 ResNet 的 BasicBlock 残差结构
